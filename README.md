# Terminal_games
Some games to be played within the terminal

First, run `make` from the main directory

Multiplayer games will requieres to use 2 PCs / 2 terminals. One must be started in server mode first

## Ascars
#### A car traffic simulator
Organize your city and avoid traffic jams !

Still in dev, sandbox mode availlable with '-s'

## Morpion
#### A multiplayer Tic-Tac-Toe game
`./morpion <server_ip> <port>`

if `<server_ip>` = '0' then starts in server mode

if `<port>` is omited, uses default port

## Toucher couler
#### A multiplayer Battleship game
`./toucher_couler <server_ip> <port>`

if `<server_ip>` = '0' then starts in server mode

if `<port>` is omited, uses default port
